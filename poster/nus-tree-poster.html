NUS-TREE

By: Arav Cabral & Raghuveer Singh

A visual degree planner for NUS students. Map prerequisites, discover what each module unlocks, import a NUSMods plan, and validate semester order.

The Problem

Planning modules across multiple years is hard because students need the full prerequisite chain, not just the one line of prerequisite text shown for a single course. A student aiming for a higher-level module may only realise later that a Year 1 or Year 2 foundation module was needed. That mistake can affect exchange plans, specialisations, or graduation timing.

Current Solution

NUS-Tree turns degree planning into one editable graph. Students can explore module paths in both directions, choose valid prerequisite alternatives, combine several goals, import an existing NUSMods timetable, and identify missing or mistimed prerequisites before registration.

What is actually working right now

The app reads live NUSMods module relationships in either direction. It builds prerequisite trees with AND, OR, and “n of” choices, builds reverse Unlocks trees from fulfilment data, and converts imported NUSMods timetables into validated study-plan graphs.

Built So Far

Live NUSMods data now powers prerequisite and Unlocks trees, guided alternative choices, multi-target planning, and NUSMods timetable import. Students can edit and colour nodes, add notes, load templates, save automatically, import/export JSON, arrange the graph, and review a validated four-year plan.

What changed

  • Unlocks mode: switch direction to recursively show modules enabled by the selected starting module.
  • NUSMods import: timetable JSON becomes semester-assigned module nodes and dependency links.
  • Import validation: unmet earlier prerequisites produce red nodes and study-plan warnings.
  • Dual import: the same menu accepts NUS-Tree exports or NUSMods timetable JSON.

Testing + CI

  • Unlocks traversal: UI coverage verifies future-module edges and recursive descendants.
  • Plan import: a captured NUSMods timetable is converted into a four-year plan.
  • Prerequisite rules: UI checks still cover ALL-required and ANY-one link semantics.
  • CI workflow: GitHub Actions runs API tests, the production build, and Playwright browser checks.

Known limits + next

  • Degree requirements: validate programme, major, minor, and specialisation rules.
  • Workload checks: surface overloaded semesters and credit shortfalls.
  • Recommendations: suggest alternative modules and paths when a preferred option is unavailable.
  • Import breadth: support more NUSMods export variants and richer plan metadata.

Why this helps now

Students can now answer “What do I need first?”, “What will this module unlock?”, and “Does my existing NUSMods plan satisfy the path?” in one place. The imported or generated graph stays editable, becoming a personal degree roadmap rather than a static lookup.

Next build target

The next target is broader degree validation: workload, programme requirements, minors, and specialisations. After that, NUS-Tree can recommend alternative routes when a module is unavailable or a prerequisite chain no longer fits the student's timeline.
